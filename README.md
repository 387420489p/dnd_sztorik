# D&D Kalandok Gyűjteménye

Üdvözlünk a Nagy Krónikában! Ez a repository a D&D csapatunk epikus (és sokszor nevetséges) kalandjainak digitalizált, regényszerű leiratait tartalmazza. 

A projekt egy elegáns, Dark Fantasy stílusú weboldalként is funkcionál, ahol kényelmesen lehet böngészni és olvasni a fejezeteket.

## 📖 Jelenlegi Kalandok

### 1. Ascheheimi Kutatás
Öt valószínűtlen hős expedíciója egy elhagyatott törpkirályságba, ahol a holtak kővé dermednek, a koboldok pedig túl sokan vannak. A történetet a cinikus kőgnóm bárd, Andror (Pepe) meséli el nekünk.

## 🚀 Fejlesztés és Működés

Az oldal **vanilla HTML/CSS** alapokon nyugszik, hogy gyors, mobilbarát és örök életű maradjon. Minden új kaland egy külön almappát kap, amire a fő `index.html`-ből lehet hivatkozni.

### Oldal Felépítése:
- `index.html` - A fő választómenü (Hub).
- `style.css` - A közös, prémium dark fantasy stílus.
- `ascheheim/` - Az "Ascheheimi Kutatás" kaland dedikált mappája a regénnyel (`index.html`) és a képekkel (`images/`).
